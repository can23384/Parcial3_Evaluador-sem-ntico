MANUAL DE CAMPO / 01

De los símbolos al significado.

  1. Define D. Escribe etiquetas separadas por comas. Después pulsa Aplicar.
  2. Declara el lenguaje. Añade nombres, tipos y aridades. Marca las tuplas de cada relación; asigna una salida a cada entrada de las funciones.
  3. Escribe la fórmula. Usa los botones o el teclado. Las constantes son funciones de aridad cero.
  4. Fija el entorno. Selecciona un valor de D para cada variable libre detectada.
  5. Evalúa y explora. Abre la traza para ver testigos, contraejemplos y las comprobaciones completas.

Sintaxis admitida

¬ ∧ ∨ → ↔ ∀ ∃ = ≠

Alternativas de teclado: ! & | -> <-> forall exists !=. También not and or.

Precedencia de mayor a menor: negación y cuantificadores, ∧, ∨, →, ↔. La implicación se agrupa a la derecha. Los cuantificadores abarcan la siguiente fórmula unaria: escribe ∀x (P(x) → Q(x)) para incluir toda la implicación.

Los nombres distinguen mayúsculas y minúsculas. Una variable es un identificador no declarado usado como término. R(x, y) usa un predicado declarado; f(x) usa una función declarada.

Reglas del proyecto

El dominio y las interpretaciones de funciones y relaciones deben ser no vacíos. Toda función debe ser total. La igualdad compara elementos de D. Una entrada inválida nunca recibe Verdadero o Falso.

Exploración y límites

El explorador estudia solo la interpretación actual: no demuestra validez lógica en todas las interpretaciones. Admite hasta 256 entornos. Límites de trabajo: 20 elementos, aridad 6, 4096 tuplas por símbolo, 32 símbolos, 512 tokens y 12 000 pasos por evaluación. Si se exceden, se informa sin asignar verdad.

Exporta el caso a JSON para conservarlo. Al importar o cargar un ejemplo se reemplaza el caso actual. Los cambios de dominio conservan únicamente las tuplas y salidas que siguen perteneciendo a D.
